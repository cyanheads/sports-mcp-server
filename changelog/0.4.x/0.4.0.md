# 0.4.0 — 2026-10-13

## Added

- **`sports_get_game`** resolves league-qualified ESPN/MLB game IDs to metadata, period scores, team totals, provider game performers, and paged scoring plays. Scheduled games return empty played-stat sections; missing scores and unplayed innings remain null. ([#30](https://github.com/cyanheads/sports-mcp-server/issues/30))

## Fixed

- **`sports_get_standings`** uses ESPN's default tables and verifies explicit seasons against served metadata, returning `season_not_found` when the season cannot be verified. ([#22](https://github.com/cyanheads/sports-mcp-server/issues/22))
- **Standings records** retain ranking groups, historical MLB division names, NHL overtime losses, and numeric zero; points apply only to soccer/NHL and college overall records avoid split-record overwrite. ([#23](https://github.com/cyanheads/sports-mcp-server/issues/23))
- **`sports_get_team`** retains flat/grouped ESPN rosters, athlete positions, nullable jerseys, and franchise venues, while excluding explicitly inactive NFL groups. ([#25](https://github.com/cyanheads/sports-mcp-server/issues/25))
- **TheSportsDB lookups** disclose the known free-key search limit on both response surfaces and preserve supplied player ESPN IDs. `totalFound` describes returned records; mixed team notices apply only to TheSportsDB contributions. ([#27](https://github.com/cyanheads/sports-mcp-server/issues/27))
