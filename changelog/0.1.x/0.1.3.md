# 0.1.3 — 2026-06-12

Maintenance pass: framework adoption, bundle hardening, and synced vendored skills.

## Added

- **`scripts/clean-mcpb.ts`** — post-pack bundle cleaner wired into the `bundle` script; runs `mcpb clean` (dev-dependency prune) then strips dependency-shipped agent-doc entries (`node_modules/**` `skills/`, `.claude/`, `.agents/`, `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach.
- **`lint-packaging.ts` bundle-content and identity guards** — new checks: root dev dirs must not survive `.mcpbignore` evaluation; `.mcpbignore` patterns must be anchored so they don't strip nested `node_modules/…/skills/` runtime paths; critical runtime package paths must not be stripped; a built `.mcpb` must carry zero `node_modules/**` agent-doc entries; `name`/`title` literals and manifest `display_name` must equal the unscoped package name.
- **`check-framework-antipatterns.ts` `coerce-boolean-env-flag` rule** — flags `z.coerce.boolean()` on env flags (`Boolean("false") === true` makes them undisableable) in favor of `z.stringbool()`; comment lines are skipped so JSDoc naming the pattern isn't a false positive.
- **Dockerfile `HEALTHCHECK`** — polls `/healthz` every 30s; adds an `APP_VERSION` build arg surfaced as the `org.opencontainers.image.version` OCI label.
- **`skills/techniques/`** — reference skill cataloguing reusable response/retrieval patterns (outline-on-overflow).

## Changed

- **Display identity** — `createApp()` now sets `name` and `title` to `sports-mcp-server`; `.codex-plugin/plugin.json` `interface.displayName` changed from `@cyanheads/sports-mcp-server` to the unscoped `sports-mcp-server`.
- **`.mcpbignore` patterns anchored** — root dev-dir entries (`skills/`, `.agents/`, `.claude/`, `Dockerfile`, `bun.lock`, etc.) now leading-slash anchored so they only match at bundle root.
- **Vendored skills synced to `@cyanheads/mcp-ts-core` ^0.10.6** — under `skills/`, `.claude/skills/`, `.agents/skills/`; `ctx.sample` removed from the Context reference, bundling docs updated for the cleaner step.
