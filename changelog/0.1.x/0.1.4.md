# 0.1.4 — 2026-08-21

Maintenance pass: framework adoption to ^0.12.3, two tool-output refinements, build and supply-chain hardening.

## Added

- **Community health files** — `SECURITY.md` (private vulnerability reporting), `CONTRIBUTING.md` (issue-first flow with server-vs-framework routing), `CODE_OF_CONDUCT.md`, `.github/FUNDING.yml`, and `.gitattributes` (LF normalization, generated-file diff markers).
- **Supply-chain guard** — `bunfig.toml` holds freshly published packages for 3 days (`minimumReleaseAge`) and runs the Socket scanner on every install.
- **Dependency-specifier gate** — new devcheck check rejects floating specifiers (`latest`/`*`/dist-tags) in `package.json` and `bun.lock`.

## Changed

- **MCP SDK v2 serving** — the server now speaks protocol revision 2026-07-28 alongside legacy-era clients.
- **Strict tool inputs** — unknown argument keys are rejected by name before the handler runs; advertised schemas declare `additionalProperties: false`.
- **`sports_get_standings` off-season notice** — moved from an output-schema field to an enrichment trailer via `ctx.enrich.notice()`; still reaches both `structuredContent` and `content[]`.
- **TypeScript 7 build** — compiled with `tsc` ^7 instead of ^6.
- **Docker image** — base images pinned to Bun 1.4.0; `--platform=$BUILDPLATFORM` keeps multi-arch builds native (Bun 1.4 aborts under QEMU emulation); production install drops optional peer tiers; BuildKit cache mounts for `bun install`.
- **Plugin-manifest identity unscoped** — `.claude-plugin/plugin.json` name/server key and the `.codex-plugin/mcp.json` key carry the unscoped `sports-mcp-server`; `npx -y` install args keep the full npm name. Canonical author field (Casey Hand).
- **Vendored skills synced to mcp-ts-core ^0.12.3** — context/enrich APIs, testing kit, linter catalog, release-skill tag-signing safeguards.

## Fixed

- **`sports_get_player` format parity** — dropped markdown italics from the Source line so `content[]` text matches the structured output styling.
