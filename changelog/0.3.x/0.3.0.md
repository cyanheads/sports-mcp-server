# 0.3.0 — 2026-10-13

## Changed

- **`sports_get_schedule`** acquires at most seven provider-calendar days and pages games with `limit` (default 100, capped at 200) and `offset`; both response surfaces expose served/requested bounds and continuation. Follow `nextOffset` with original bounds, then `nextDateFrom` retaining `requestedDateTo`. [#29](https://github.com/cyanheads/sports-mcp-server/issues/29)
- **Single-team selectors** prefer exact canonical names or abbreviations and reject ambiguous partial matches with `ambiguous_team` and candidates; retry with a supplied exact name or abbreviation. [#26](https://github.com/cyanheads/sports-mcp-server/issues/26)

## Fixed

- **Score dates and schedule membership** use the US Eastern day for omitted score dates and preserve provider-calendar games across UTC midnight; invalid or reversed schedule bounds fail before fetching. [#19](https://github.com/cyanheads/sports-mcp-server/issues/19)
- **Empty scores** distinguish `no_games` from `no_team_matches` through typed enrichment and notices while retaining compatible `reason`. [#17](https://github.com/cyanheads/sports-mcp-server/issues/17)
- **College coverage** uses complete ESPN team inventories, men's Division I basketball scoreboards, and FBS football scoreboards with explicit coverage. [#20](https://github.com/cyanheads/sports-mcp-server/issues/20), [#21](https://github.com/cyanheads/sports-mcp-server/issues/21)
- **ESPN team schedules** merge soccer results/fixtures and US sport phases using the provider season year; summaries return latest completed games and upcoming scheduled instants in order. [#24](https://github.com/cyanheads/sports-mcp-server/issues/24)
- **Documented serving commands** execute Node when launched with `bun run`; registry npm launch metadata selects the bin and fixes HTTP transport explicitly. [#28](https://github.com/cyanheads/sports-mcp-server/issues/28)
- **Build and verification tooling** sync framework skills and packaging gates, remove unused musl dependencies from glibc images, refresh CodeQL categories, and exclude environment and registry credentials from image contexts.
