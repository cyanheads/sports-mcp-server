# 0.2.1 — 2026-08-30

## Fixed

- **`sports_get_schedule`** sends paired league-wide date ranges to ESPN and MLB, retaining MLB games on their provider calendar date when UTC crosses a date boundary. [#5](https://github.com/cyanheads/sports-mcp-server/issues/5)
- **`sports_find_team`** recognizes provider-specific TheSportsDB league aliases so merged cross-source team records retain source metadata. [#6](https://github.com/cyanheads/sports-mcp-server/issues/6)
- **Docker production image** builds with Bun and runs the server under non-root Node 24 with a Node health check. [#11](https://github.com/cyanheads/sports-mcp-server/issues/11)
