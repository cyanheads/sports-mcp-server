- **Tool descriptions** clarify advisory sport hints and response fields. [#10](https://github.com/cyanheads/sports-mcp-server/issues/10)
- **README and `.env.example`** document the stateless session default and advisory `sport` behavior. [#9](https://github.com/cyanheads/sports-mcp-server/issues/9) [#12](https://github.com/cyanheads/sports-mcp-server/issues/12)
