# 0.5.0 — 2026-10-17

## Changed

- **`sports_get_standings` rank** is null when the provider has no valid group position (`number` → `number | null`). Valid provider positions preserve ties and sort within each group, with unknown positions last. [#35](https://github.com/cyanheads/sports-mcp-server/issues/35)
- **Scores and standings pagination** defaults to 100 rows and caps at 200, with `limit`, `offset`, totals, and continuation on both response surfaces. Follow `nextOffset` with the same filters; exhausted pages retain the true total. [#36](https://github.com/cyanheads/sports-mcp-server/issues/36)

## Fixed

- **Optional-source disclosure** identifies failed ESPN/MLB team contributions and MLB standings metadata lookups in `unavailableSources`. Useful results survive; empty degraded team searches return `sources_unavailable` rather than `no_match`. [#33](https://github.com/cyanheads/sports-mcp-server/issues/33)
- **MLB game rates** derive AVG/OBP/SLG/OPS/ERA/WHIP from game counts, using outs for pitching rates. Missing operands or zero denominators yield null under the existing statistic names. [#34](https://github.com/cyanheads/sports-mcp-server/issues/34)
- **Team badges and venues** merge missing metadata for matching provider IDs before name deduplication, preserving populated fields. TheSportsDB supports current `strBadge` and legacy `strTeamBadge`. [#37](https://github.com/cyanheads/sports-mcp-server/issues/37)
- **Formatted provider values** escape HTML and Markdown while preserving authored structure, verbatim structured values, and complete fenced biographies. [#38](https://github.com/cyanheads/sports-mcp-server/issues/38)
- **Startup regression checks** retain bounded readiness checks with a 30-second deadline and 45-second test timeout under host load.
