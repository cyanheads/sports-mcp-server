# 0.6.1 — 2026-11-20

## Added

- **Game status detail** carries ESPN and MLB provider text such as `Final/OT`, `Final/SO`, and rain delays into game records and text output. The single-game heading omits the date and the game row retains the full UTC start time. ([#46](https://github.com/cyanheads/sports-mcp-server/issues/46))
- **`sports_get_game` section selection** accepts `sections: ["scoringPlays"]` for play-only continuation. Omit `sections` for the full response or use `[]` for game and paging metadata. Excluded arrays are empty and listed in `omittedSections`. ([#50](https://github.com/cyanheads/sports-mcp-server/issues/50))

## Changed

- **Runtime and configuration** require Bun 1.4.4 or later. Relative `LOGS_DIR` paths resolve against the server package directory. The environment example documents HTTP URL and route settings, JWT issuer and audience, and request-state sealing.
- **Desktop bundle cleanup** preserves the SDK's runtime skill modules while removing package-root agent docs.

## Fixed

- **ESPN pregame records** return null scores and clocks until play starts. ([#44](https://github.com/cyanheads/sports-mcp-server/issues/44))
- **Unknown MLB games** return `game_not_found` with the game ID recovery hint when the feed returns its HTTP 200 unknown-game placeholder. ([#45](https://github.com/cyanheads/sports-mcp-server/issues/45))

## Security

- **TheSportsDB HTTP errors** keep upstream response bodies out of both MCP response surfaces, including when scrubbing the API key from error fields.
